# Contributing

Thanks for contributing to the WiCSE Intro to GitHub workshop repository!

## Our Workflow

Follow these steps when making a contribution:

1. Fork this repository
2. Clone your fork
3. Create a feature branch
4. Make your changes
5. Commit your changes
6. Push your branch
7. Open a pull request
8. Review your changes
9. Merge your pull request

## Branch Naming

Use the following format:

`feature/your-name`

Example:

`feature/ashly`

## Your Contribution

For the workshop challenge, create a profile inside the `participants` folder.

Use this format:

`participants/your-name.md`

Your profile should include:

- Name
- Major
- School
- Year
- Something you're currently learning
- GitHub username
